## Looping

In Redux Saga a common pattern for looping is as follows:
```javascript {2}
function* watcher() {
  while (true) {
    const action = yield take(ACTION)
    yield fork(worker, action.payload)
  }
}

function* worker(payload) {
  // ... do some stuff
}
```

In Redux Sonnet, the declarative nature of [`Effect.forever`][effect-forever] is
more appropriate:

```ts twoslash {10}
/// <reference types="effect" />
// @paths: {"redux-sonnet": ["../packages/redux-sonnet/src"], "redux-sonnet/*": ["../packages/redux-sonnet/src/*"]}
// ---cut---
import { Effect, Option } from "effect"
import { Operators } from "redux-sonnet"

declare const worker: (action: unknown) => Effect.Effect<void, never, never>

const watcher = Effect.gen(function*(){
  const action = yield* Operators.unsafeTake(Operators.ofType('ACTION'))
  yield* Effect.fork(worker(action))
}).pipe(
  Effect.forever
)
```

## Interruption

Redux Saga provides a specialized `END` action for terminating running "effects."

```javascript {10}
import { END } from 'redux-saga'
import { takeEvery } from 'redux-saga/effects'

function* root() {
  yield takeEvery("ACTION", worker)
}

function* worker(payload) { /* ... */}

store.dispatch(END)
```

In Redux Sonnet, we instead may interrupt the forked fiber responsible for
managing the root Stanza. There is no concept of a special action.

See
[`packages/redux-sonnet/test/redux-saga/operators/takeEvery.test.ts`][takeEvery-test]
for additional exemplification.

```ts twoslash {14}
/// <reference types="effect" />
// @paths: {"redux-sonnet": ["../packages/redux-sonnet/src"], "redux-sonnet/*": ["../packages/redux-sonnet/src/*"]}
// ---cut---
import { Effect, Fiber, pipe } from "effect"
import { Sonnet, Operators } from "redux-sonnet"

declare const worker: (action: unknown) => Effect.Effect<void, never, never>

const root = Effect.gen(function*(){
  yield* Operators.takeEvery(Operators.ofType('ACTION'), worker)
})

const sonnet = Sonnet.make(root, Sonnet.defaultLayer)

await pipe(
  sonnet.fiber,
  Fiber.interrupt,
  Effect.runPromise,
)
```

[effect-forever]: https://effect-ts.github.io/effect/effect/Effect.ts.html#forever
[takeEvery-test]: https://github.com/ehegnes/redux-sonnet/blob/main/packages/redux-sonnet/test/redux-saga/operators/takeEvery.test.ts
